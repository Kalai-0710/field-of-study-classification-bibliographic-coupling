DATA

The Web of Science exports and the derived dataset.csv are not included in
this repository because Web of Science records are licensed content. To
reproduce the dataset, search the Web of Science Core Collection using the
Web of Science Categories field for each of the ten categories (Computer
Science, Artificial Intelligence; Computer Science, Information Systems;
Engineering, Electrical & Electronic; Mathematics; Physics, Applied;
Chemistry, Multidisciplinary; Environmental Sciences; Psychology,
Multidisciplinary; Biotechnology & Applied Microbiology; Materials Science,
Multidisciplinary), restricted to articles in English published 2020-2024,
sorted by times cited, and export the top 1,000 records per category as
"Full Record and Cited References" plain text in batches of 500.
